# ADR 0002 — Rust as implementation language

- Status: accepted
- Date: 2026-10-06
- Phase: Fase 1

## Context

Need a single binary, fast file processing, real cross-platform support (Windows/macOS/Linux, x64 + ARM64) and no runtime prerequisite for users.

## Decision

Rust, 2024 edition, Cargo-only build, MSRV 1.97.0 (documented + CI-tested). `rustfmt` + Clippy gates.

## Consequences

- No Node/Python runtime dependency for end users.
- Prototype-in-other-language allowed only if it accelerates validation without coupling the architecture.
- Every dependency judged on license, maturity, size, performance and platform behavior.
